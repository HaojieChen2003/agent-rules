# Agent Rules — 个人领域规则管理器

面向 AI Agent 的**可执行、版本化**个人领域规则库。把高频任务（书库管理、数学推导、LaTeX 排版、微信读书、编码）沉淀为机器可直接读取和执行的规则，并用 git 管理变更历史。

## 设计目标

- **机器可读**：规则以结构化 markdown 组织，frontmatter 声明触发条件（`when_to_use` / `do_not_use`），正文为"条件 → 动作"式条目。
- **速度优先**：入口只做路由，命中框架后按需读取；git 提供增量读取协议（`git log` + `git diff` 只读变更，不全量重读）。
- **可回滚**：规则改动逐版本提交，改坏可 `git checkout` / `git revert` 还原。

## 目录结构

```
Agent Rules/
├── AGENTS.md              # 总入口：激活规则、技能清单、指令优先级、危险操作分级
├── Calibre书库管理.md     # Kindle 书库：元数据、丛书识别、封面、评分、双写原则
├── 微信读书Skill.md       # 微信读书：搜索、书架、阅读统计、评分算法
├── Latex排版助手.md       # 中文 LaTeX：编译、GB/T 7714、公式环境、盲审
├── 数学工作者.md          # 数学：推导、证明、数值验证、PDE/Galerkin
├── Coder.md               # 编码：代码审查、技能与插件开发
├── references/math/       # 数学框架参考：严格性、数值、工作流、笔记设计
└── evals/                 # 回归案例
```

## 使用方式

1. **读取入口**：任务开始先读 `AGENTS.md`，按技能清单路由到对应框架。
2. **按需加载**：只读命中框架的所需章节；`references/` 为教程细节，按需查阅。
3. **遵守硬性边界**：规则中标记为"硬性"的边界（危险操作、数据安全）优先级高于默认策略，违反前必须确认。

## 版本控制

- 每次规则修改独立提交（commit message 格式：`<框架>: v<版本> <改动摘要>`）。
- 版本号与提交对齐：`version` / `last_updated` 变更伴随一次 commit。
- 远程仓库为公开备份，本机为主工作副本。

## 说明

规则中的绝对路径为本机路径，仅作参考；实际使用时请替换为你自己的环境路径。
