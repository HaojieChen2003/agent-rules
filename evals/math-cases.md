# 数学规则固定回归案例

每次只修改一类规则，然后使用同一组案例检查路由、边界和最低验收。评估规则行为，不要求把每个案例都写成完整长答案。

## 通用数学

1. 解释一致连续，包含严格定义、与逐点连续的区别、正例、反例和判断方法。
2. 解一个平方后可能产生增根的根式方程，检查原定义域和最终解集。
3. 检查一个交换极限与积分但未给条件的证明，定位首个错误并给最小修正。
4. 用户要求直接答案时，不进入训练模式或连续追问。
5. 用户说“考我，不要先给答案”时，使用递进提示并在错误后给同结构变式。

## PDE、Galerkin 与正交基

6. 推导极坐标或一般坐标变换中的 Jacobian，明确映射方向、区域、测度和绝对值。
7. 使用 Legendre 正交关系计算系数，明确标准区间、权函数和归一化约定。
8. 声称某个 Legendre 展开有限时，必须说明多项式次数、空间闭合或投影依据。
9. 推导 Galerkin 质量矩阵，检查低阶基、对称性、正定性或退化条件。
10. 从弱形式得到离散系统时，说明分部积分、边界项、试验/检验空间和边界条件。

## 符号与数值验证

11. 用 SymPy 验证恒等式，检查假设、分母和定义域，并说明验证不等于理论证明。
12. 用 NumPy 展示病态矩阵误差，报告条件数、残差与真实误差的区别。
13. 展示数值收敛阶时至少使用三个有效分辨率，区分实验阶与理论证明。
14. 用户要求“不要数值积分，要解析结果”时，优先给闭式；若无已知闭式，说明障碍，不编造结果。
15. 合法的 Green 函数或积分表示可以作为精确结果，但不能冒充已完成的初等闭式。

## 笔记、文件与 LaTeX

16. 将概念整理为标准 Markdown 笔记，不机械生成所有可选组件。
17. 将证明写入已有 `.tex`，保留宏、标签、引用和符号约定，并完成编译验收。
18. 用户说“先不要写入”时不碰项目文件；用户一开始明确要求写入时不重复确认。
19. 新建正式数学图形且项目无既有方案时，先询问 TikZ/PGFPlots/Asymptote 或 Python；一次性诊断图无需阻断。
20. 普通数学学习笔记不套用学位论文结构、盲审或学校规范。
