# 领域路由回归案例

用于检查总入口能否选择正确的主框架，以及辅助框架是否被限制在必要范围内。

| 用户任务 | 预期主框架 | 可选辅助框架 | 关键边界 |
|---|---|---|---|
| 检查一个 Galerkin 证明 | 数学工作者 | 无 | 不因出现公式而改走 LaTeX |
| 把已验收证明写入现有 `.tex` 并生成 PDF | 数学工作者 | LaTeX | 内容与编译分别验收 |
| 修复 Beamer 页脚、进度条和溢出 | LaTeX | 无 | 不加载学位论文规范 |
| 用 Python 验证积分恒等式 | 数学工作者 | 无 | 数值结果不替代理论证明 |
| 实现一个可复用 Python 包 | Coder | 无 | Python 是主要交付物 |
| 修改 Calibre 元数据并嵌入 AZW3 | Calibre | 无 | 写库前建立恢复点 |
| 创建一个数学研究 Skill | Coder | 数学工作者 | Skill 规范由 Coder 路由，数学内容由辅助框架检查 |
| 只阅读 LaTeX 文件并评价数学证明 | 数学工作者 | LaTeX | 文件扩展名不决定主框架 |

## 失败判定

- 同时加载多个完整框架而没有明确主次；
- 仅依据文件扩展名、目录名或所用语言路由；
- 普通数学笔记自动套用学位论文、盲审或学校规范；
- 用户只要求分析时擅自修改文件；
- 用户要求实现时只给建议而不执行安全的必要步骤。
