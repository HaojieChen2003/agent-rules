# Beamer 工程规则

## 1. 结构

- 所有可见内容位于完整的 `frame` 中；`\end{document}` 位于文档末尾。
- 长内容优先拆分为语义完整的多帧；自动分页只在内容连续且标题复用合理时使用。
- 帧内层级使用 Beamer 兼容结构，不把正文文档的章节命令机械搬入幻灯片。

## 2. 数学内容

- 多行公式使用合法的对齐环境，避免裸露的对齐符和换行命令。
- 超宽公式优先按语义拆行，其次调整局部字号；不能仅缩小到难以阅读。
- 数学字体和上下标遵循 `math-typography.md`。

## 3. 主题与版面

判断视觉异常前，先区分文档内容、主题默认装饰和真正的排版错误。用户未要求改版时保留项目主题、配色和导航体系；需要修改时优先覆盖最小模板组件。

## 4. 验收

- frame 配对完整，文档结束位置正确；
- 无不可接受的横向或纵向溢出；
- 标题、页码、进度和导航元素符合任务要求；
- 关键公式、图表和脚注在投影视距下可读；
- 编译、引用和字体检查通过。
