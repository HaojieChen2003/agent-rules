# LaTeX 编译与诊断

## 1. 识别工具链

先检查文档类、项目说明、编辑器配置、构建脚本和文献宏包。沿用项目已有工具链；没有约定时再根据中文支持、字体和文献系统选择编译器。

常见最小流程：

- 无文献更新：运行 LaTeX；需要稳定目录和交叉引用时再运行一次。
- `biblatex` 且文献发生变化：LaTeX → Biber → LaTeX → LaTeX。
- 不含文献的文档不机械运行 Biber。

是否需要文献处理应根据引用命令、数据库变化、现有 `.bbl` 和日志判断，而不是只看文件是否存在。

## 2. 根因诊断

1. 从首个阻断性错误开始，不被后续连锁报错分散注意力。
2. 报错行可能只是语法状态最终失衡的位置；结合最近修改定位真正根因。
3. 修改文档类、宏包或文献系统后，旧辅助文件可能污染构建；确认可再生成后再清理相关缓存。
4. 必要时构造最小复现，区分项目内容、主题、宏包和工具链问题。
5. 用户可能并行编辑文件时，用稳定文本标记重新定位，不依赖旧行号。

## 3. 产物处理

项目构建文件留在项目既有输出位置。`.aux`、`.bcf`、`.bbl`、目录、索引和 SyncTeX 等文件是否保留取决于项目约定和增量构建需求，不能一刀切。清理前列出精确目标，确保它们可再生成且确由当前任务产生。
