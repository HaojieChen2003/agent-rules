# LaTeX 数学字体与语义

## 1. 基本原则

数学字体应表达对象的语义角色。默认数学斜体表示变量；直立体通常表示名称、缩写、说明性标签、标准算子或单位。不要仅凭字符长度机械转换字体。

## 2. 上下标

### 变量下标

下标本身是变量、指标或自由参数时保持斜体：

```latex
a_i,\qquad u_h,\qquad x_{ij},\qquad \lambda_k.
```

### 语义标签

下标表示名称、类别、状态或英文缩写时使用直立体：

```latex
c_{\mathrm{cap}},\qquad
p_{\mathrm{in}},\qquad
p_{\mathrm{out}},\qquad
T_{\mathrm{ref}},\qquad
u_{\mathrm{max}}.
```

因此 `c_{cap}` 通常不合适：TeX 会把它解释为三个斜体变量 `c a p` 的并列。若 `cap` 确实代表三个变量的乘积，则应保留斜体并用更清楚的结构表达。

### 文本说明

完整词语或自然语言说明使用 `\text{...}`：

```latex
E_{\text{initial}},\qquad
E_{\text{初始}},\qquad
u_{\text{边界}}.
```

同一项目应统一英文短标签采用 `\mathrm` 还是 `\text`。通常无空格的短缩写适合 `\mathrm`，自然语言片段适合 `\text`。

## 3. 函数、算子与微分

- 使用标准命令：`\sin`、`\cos`、`\log`、`\exp`、`\det`。
- 自定义多字母算子使用 `\operatorname{}` 或在导言区声明数学算子。
- 微分符号、虚数单位和自然常数是否使用直立体，应遵循项目或学科既有约定，并在全文保持一致。

## 4. 向量、矩阵、集合与单位

- 向量和矩阵沿用项目已有的 `\mathbf`、`\boldsymbol` 或自定义宏，不在局部任务中擅自改变体系。
- 标准数集通常写作 `\mathbb{R}`、`\mathbb{C}`、`\mathbb{N}`。
- 单位使用直立体；项目已有 `siunitx` 时使用其命令，避免手工制造不一致的间距。

## 5. 编辑检查

1. 判断字符是变量、标签、算子还是文本；
2. 查找同类对象在项目中的既有写法；
3. 统一同一语义类别，不对所有上下标全局替换；
4. 编译后检查字体、间距、断行和数学含义是否同时正确。
