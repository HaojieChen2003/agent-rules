# LaTeX 安全编辑

## 1. 修改前

- 识别主文件、包含关系、自定义宏、停用区和生成文件；
- 查看用户已有改动，限定本次编辑范围；
- 对批量或结构性修改建立可验证的恢复点。

## 2. 批量修改

批量替换必须使用精确边界，并保护命令、数学环境、代码、TikZ 和其他不应处理的区域。写盘前统计命中数；命中范围与预期不符时停止。存在前缀关系的标识符应避免二次替换和子串误伤。

不要用普通文本替换器假定反斜杠、花括号和替换字符串没有特殊语义。复杂改动优先使用可审查的脚本或小范围补丁。

## 3. 修改后

- 扫描旧写法和异常残留；
- 检查环境、花括号、标签和引用；
- 编译并从首个错误诊断；
- 查看关键页面，确认没有静默丢失内容；
- 只清理本任务产生且确认可再生成的临时文件。
