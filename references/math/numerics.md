# Python、符号计算与数值实验

## 1. 工具选择

| 任务 | 首选 |
|---|---|
| 符号化简、精确积分、恒等式与级数 | SymPy |
| 数组、向量化、稠密线性代数 | NumPy |
| 稀疏计算、优化、积分、插值、ODE | SciPy |
| 高精度与浮点误差诊断 | mpmath |
| 科学绘图 | Matplotlib 或项目既有方案 |

选择最少依赖；能用标准库清晰完成时不增加第三方依赖。不得混淆符号结果、任意精度数值和机器浮点近似。

## 2. 代码合同

- 教学片段以清晰和最少依赖为先；
- 验证脚本必须包含参考结果、测试值和误差说明；
- 项目模块应职责单一，并按项目约定提供类型、异常处理和测试；
- 数值实验记录参数、精度、随机种子、停止准则和输出路径；
- 绘图代码应可复现，坐标轴、单位、图例与保存路径明确；
- 检查非法输入、定义域、形状和数据类型。

## 3. 数值风险

按需检查：

- 浮点舍入、灾难性消减、溢出与下溢；
- 尺度差异、条件数和病态问题；
- 迭代收敛、初值敏感性与停止准则；
- 离散、截断、求积和采样误差；
- 随机波动与可复现性；
- 低精度偶然吻合；
- 用数值现象替代理论证明。

## 4. 验证合同

实验必须回答：

```text
理论结论是什么？
实验验证了哪个有限范围的命题？
实验不能证明什么？
参考结果是否独立于待验证实现？
误差可能来自哪里？
在哪些参数或边界附近可能失效？
```

优先比较待验证实现与独立参考实现，同时报告绝对误差和相对误差。测试覆盖正常值、边界值、低阶可手算值和可能失稳的值。

SymPy 验证恒等式时，除检查化简为零外，还要检查表达式定义域、分母、分支和隐含假设。随机代入只能作为辅助证据。

## 5. PDE 与离散方法专项

处理 PDE、Galerkin、谱方法或有限元数值实验时，按需区分：

- 空间离散误差与时间离散误差；
- 基函数截断误差与数值求积误差；
- 迭代求解误差与浮点误差；
- 稳定性、相容性和收敛性；
- 连续范数、离散范数和加权内积；
- 网格尺度、时间步长、多项式阶数和容差。

经验收敛阶至少使用三个有效分辨率，并说明是否进入渐近区间。观测到斜率不等于理论收敛性证明。

矩阵实验优先报告尺寸、结构、对称误差、最小/最大特征值或奇异值、条件数，以及求解残差和真实误差的区别。

## 6. 可视化边界

图形用于解释结构、发现异常和展示数值现象，不用于证明一般命题。对数坐标、归一化、截断范围或筛选数据必须在图注或说明中披露。
