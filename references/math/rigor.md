# 数学严谨性

## 1. 输入合同

推导前按需明确：

- 研究对象及其类型；
- 变量、定义域、参数范围和边界；
- 已知条件、目标和额外假设；
- 结论是精确或近似、局部或全局、存在或唯一；
- 所有符号、内积、范数、测度和归一化约定。

必要时区分定义、已知、假设、推导、结论、验证与不确定内容，但不把标签机械用作装饰。

## 2. 定义与定理

解释定义时覆盖对象、条件、结论和适用范围；优先给一个正例，以及一个反例或边界例。直觉帮助理解，但不能代替严格定义。

陈述定理时分开条件与结论。调用定理前逐项核对条件；关键条件删除后会失败时，给出最小反例或说明失效机制。

## 3. 推导与证明合法性

可以压缩机械计算，但不得省略：

- 等价变形的依据；
- 除法时分母非零；
- 开方、平方、取对数、反函数等操作的定义域和可逆性；
- 变量代换的映射方向、可逆性、Jacobian 与区域变化；
- 极限、积分、求和或微分交换的条件；
- 分类讨论的完备性；
- 定理调用条件和量词顺序；
- 充分、必要、充要关系；
- 存在性、唯一性、有界性、正则性与收敛性。

第一性原理分析采用：

```text
定义 → 最简单情形 → 结构或不变量 → 一般化 → 边界检查 → 独立验证
```

## 4. 解集与边界

方程、不等式、极值、参数问题和微分方程至少按需检查：

- 原定义域以及变形产生的增根或漏解；
- 参数区间是否穷尽；
- 开区间、闭区间和退化边界；
- 局部结论与全局结论；
- 必要条件是否被误当作充分条件；
- 解是否存在、唯一以及属于哪个函数空间。

## 5. 证明纠错

检查用户证明时：

1. 判断“正确 / 部分正确 / 错误 / 信息不足”；
2. 定位第一个使后续推理失效的步骤；
3. 说明缺失条件、非法变形或逻辑断点；
4. 给出最小修正；
5. 用户需要时再给完整重写；
6. 说明如何自行识别同类错误。

## 6. 独立验证

复杂结果至少使用一种独立验证；高风险推导优先两种：

1. 代回原式；
2. 反向推导；
3. 特殊值、低阶情形或退化极限；
4. 量纲、对称性、符号或奇偶性；
5. 手算基准问题；
6. 符号计算或高精度数值抽样；
7. 与已知定理对照；
8. 构造反例。

明确说明验证支持什么、不能证明什么，以及仍依赖哪些未验证条件。

## 7. 禁止行为

不得把有限样本、图像或 CAS 输出当成一般性证明；不得默认逆矩阵、极限、最优解、级数展开或迭代收敛存在；不得用模糊自信掩盖定义域、量词、边界或条件缺口。
