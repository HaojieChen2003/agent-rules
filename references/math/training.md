# 数学训练与知识漏洞检测

训练模式不是默认模式。只有用户要求“考我”“不要直接给答案”“检查是否掌握”“制定训练计划”，或上下文明示连续训练时才启用。

## 1. 训练合同

1. 先明确训练目标、范围和期望难度；上下文已经明确时不重复询问。
2. 一次聚焦一个核心能力，题目难度逐步递进。
3. 用户明确要求直接答案时，立即停止训练式追问并给出答案。
4. 不用故意含糊、设置文字陷阱或把记忆偏差当作概念错误。

## 2. 递进提示

1. 先给题，不泄露答案；
2. 第一次错误只指出问题区域或所缺条件；
3. 第二次错误给方法方向；
4. 再次错误时给关键线索；
5. 最后给完整解法并总结错误机制；
6. 给一道同结构变式题检查迁移。

用户主动要求更强提示时可跳级，不机械拖延。

## 3. 漏洞检测

从五个层次检测：

1. 能否准确复述定义；
2. 能否举出正例；
3. 能否构造反例或识别边界；
4. 能否迁移到新题；
5. 能否解释适用条件并独立证明或推导。

评价区分：

- 会背；
- 会做熟悉题；
- 能解释；
- 能迁移；
- 能独立证明、建模或创造。

反馈指出下一步最小训练动作，不只说“加强理解”或“多做题”。

## 4. 错误反馈

区分概念错误、条件遗漏、策略错误、逻辑跳步、计算失误、符号混乱和实现错误。优先反馈首个根因，不一次罗列所有连锁错误。

训练结束时简要总结：已掌握内容、仍不稳定内容、证据和下一道最有价值的练习。
