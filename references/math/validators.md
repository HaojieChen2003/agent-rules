# 数学任务统一验证与验收

只运行与当前任务相关的检查。检查失败时给出证据，不笼统声称完成。

## A. 内容正确性

- 对象、变量、定义域、参数、测度和符号是否明确；
- 定理条件、量词和充分必要关系是否满足；
- 等价变形、变量代换和交换操作是否合法；
- 是否存在增根、漏解、分类遗漏或边界遗漏；
- 存在性、唯一性、有界性、正则性与收敛性是否处理；
- 结论是否超过证据；
- 数值、图像或 CAS 是否被误当作证明；
- 是否至少完成一种适当的独立验证。

## B. 数值与代码

- Python 是否可运行，输入输出和依赖是否明确；
- 符号计算的假设、分支和定义域是否匹配；
- 是否提供独立参考、误差指标和边界测试；
- 随机种子、精度、停止准则和输出路径是否明确；
- 是否区分残差、误差、截断误差和浮点误差；
- 数值结论是否被限制在实验支持的范围内。

## C. Markdown 与 LaTeX

- Markdown 层级、代码围栏和公式分隔符是否闭合；
- LaTeX 括号、环境、命令参数和多行对齐是否正确；
- 标签、引用、文献键和模板公开接口是否保留；
- 编译命令退出状态是否正常，PDF 与图片是否生成；
- 是否存在未定义引用、乱码、裁切、重叠或不可读内容；
- overfull/underfull 等剩余警告是否评估并报告。

## D. 项目完整性

- 是否只修改必要文件并保留用户现有改动；
- 是否破坏自定义命令、数学环境、引用键或目录；
- 是否引入无关依赖；
- 代码、图片、数据和构建产物是否位于规定目录；
- 临时文件是否只清理本任务创建的精确目标；
- 是否报告剩余警告和无法验证项。

## E. 验收状态

统一使用：

- **通过**：适用检查均完成，没有已知阻断问题；
- **通过但有非阻断警告**：目标已完成，仍有不影响交付的警告；
- **部分通过**：部分目标完成，明确列出未完成项及影响；
- **未通过**：存在阻断性错误或结果不满足目标；
- **无法验证**：缺少必要环境、数据、工具或条件，说明缺口和可执行的下一步。

最终报告至少包含：结论、验证方式、验收状态，以及仍存在的警告或不确定项。
