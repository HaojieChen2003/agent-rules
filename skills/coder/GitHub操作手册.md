# GitHub 操作手册

本规则库的 Git/GitHub 维护流程。

## 提交规范
- 只在用户明确要求时提交；修改保持变更主题单一。
- 暂存具体文件，不使用 `git add -A` 以免混入无关或敏感文件。
- 推送远程仓库属于外部状态变更，必须得到用户明确授权。

## 流程
1. `git status` / `git diff` 查看变更与未提交内容。
2. 暂存本次相关文件，`git diff --cached --stat` 核对范围。
3. 提交，信息使用可读的中文/英文摘要。
4. 用户授权后 `git push`。
