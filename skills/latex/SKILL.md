# latex — LaTeX 工程框架

处理已有 LaTeX 工程中的定向任务，以安全编辑、工具链兼容、语义清晰和可验证产物为目标。普通 LaTeX、Beamer 和学位论文共享工程原则，但只加载当前任务需要的专项纪律。

## 核心原则
1. **项目优先**：沿用现有文档类、编译器、文献系统、目录、宏、标签、字体和设计语言。
2. **最小充分流程**：根据项目实际依赖选择编译步骤，不机械运行 Biber，不默认启用 `shell-escape`。
3. **内容与产物分开验收**：编译成功不代表数学、引用、编号、术语或视觉版面正确。
4. **根因优先**：先定位第一个阻断性根因，检查最近修改与缓存，不用无关改动掩盖错误。
5. **安全编辑**：批量修改限定匹配范围、保护特殊环境、写盘前核对命中数量，写盘后扫描残留并编译验证。
6. **语义排版**：数学字体表达对象的数学角色；变量、说明性文字、算子、集合和单位使用相应字体。

## 安全与验证（常驻纪律）
- 写盘前解析并核对精确目标；不自作主张清理目标外内容。
- 编译退出成功不等于内容正确；按风险检查引用、编号、术语与版面。
- 临时产物按精确范围处理，正式源文件和必要缓存不误删。
- 报告必须区分：已确认 / 推断 / 未知 / 残余风险。

## 细分纪律（命中必读 `references/optional/`）
- 编译失败 / 工具链 / 缓存 → `references/optional/compile.md`
- 公式 / 符号 / 上下标 / 数学字体 → `references/optional/typography.md`
- Beamer 幻灯片 → `references/optional/beamer.md`

## 路由（主框架边界）
- 数学内容写入 `.tex` 时，math skill 负责内容正确性，本 skill 负责安全写入/编译/验收，分别报告。
- 纯数学任务不归本框架；普通 `.tex` 不自动视为学位论文。

## 验收（最低）
1. 编译退出状态正常，目标 PDF 生成；
2. 无新增未定义引用、标签、文献或控制序列；
3. 自定义命令、数学环境、引用键和目录结构未被破坏；
4. 数学字体、上下标、算子和单位语义一致；
5. 关键页面无不可接受溢出、遮挡、截断或层级混乱；
6. 临时产物按精确范围处理，正式源文件和必要缓存未被误删。
