# latex-typography — 数学字体、公式与符号

公式、符号、上下标和数学字体编辑的语义排版纪律。

## 核心要点
- 数学模式默认把字母解释为变量并使用斜体；多字母组成的名称/类别/缩写/说明性上下标不误排成变量乘积。
- 单字母变量下标保持数学斜体；说明性或语义性下标用直立罗马体；完整自然语言说明用 `\text{...}`。
- 标准函数和算子使用已有命令或 `\operatorname`，不用普通斜体拼写。
- 数集和固定结构按语义用黑板粗体或项目约定；向量/矩阵粗体方案沿用项目既有约定。
- 编辑时先判断下标是"变量"还是"标签"，不得对所有下标机械添加 `\mathrm`。
