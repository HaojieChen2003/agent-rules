# math-pde-galerkin — PDE、Galerkin 与正交基

低频专用纪律，仅当任务命中 PDE/Galerkin/正交基时读取。

## 核心要点
- 连续对象与离散对象必须明确对应；边界项、权函数和误差来源明确。
- 数值观察到的稳定性、收敛阶或有限样本规律不得直接写成理论证明。
- 使用 Legendre 正交关系时明确标准区间、权函数和归一化约定。
- 声称有限展开时必须说明多项式次数、空间闭合或投影依据。
- 从弱形式得到离散系统时，说明分部积分、边界项、试验/检验空间和边界条件。

> 完整结果（闭式、符号、数值方案、工具选型）以原 `Agent Rules/references/math/pde-galerkin.md` 与 `numerics.md` 为正本。
