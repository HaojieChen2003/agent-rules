# math-rigor — 严谨性与独立验证纪律

数学主框架对证明、边界处理和独立验证的细化规则。

## 核心要点
- 数学严密性：先给根本性解释（如 Legendre 三项递推来源、有限展开为何成立、坐标变换 Jacobian 方向与测度变化）。
- 优先给可核验的解析推导；数值实验作为独立验证或失效诊断，不替代解析论证。
- 不引入与任务无关的符号约定；同一对象沿用项目已有记号。
- 检查用户证明时先定位首个使后续推理失效的步骤，再给最小修正；用户需要时才完整重写。
- 不默认逆矩阵、极限、级数展开、弱解、最优解或数值迭代收敛存在；不未经说明交换极限/积分/求和/微分；不忽略定义域、量词、边界、存在性、唯一性和收敛条件。
- 不把有限样本、CAS 输出或图像观察写成一般性证明。
